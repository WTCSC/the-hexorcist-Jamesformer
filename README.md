# The hexorcist hex converter
this program takes a number string in a certain base and than converts that number string into another base up to base-32

## requirements
this program requires the following to work: 
**Python version 3.12 or higher** and
**Git version 2.51 or higher**

## installation
you need to copy the following command into your console to install this program: 
```
git clone (your hex repository URL)
```
## example
the code should look like this in the terminal
```
welcome to the hexorcist prepared to get a hexorcisim
What is your number string: (example string)
what is the original base: (example base)
what is the base you are trying to get to: (example base)
your hexed number in base-10 is: 
(example base number)
your hexed number in base (example target base) is: 
(Example final base)
```
